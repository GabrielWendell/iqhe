# Data availability

## Repository status

The current project uses deterministic model calculations only. It does **not** depend on a
proprietary, observational, or experimentally restricted dataset. The numerical inputs are the
version-controlled model and figure configurations in `configs/`; the reusable implementation is in
`src/qhe/`; and the generated numerical/visual products are regenerated by the scripts in `scripts/`.

For the `v0.6.0` release, the repository contains the code, teaching notebooks, tests, configurations,
caption sources, and release metadata needed to reproduce the validated static results. The primary
online code location is:

```text
https://github.com/GabrielWendell/qhe-ejp
```

Before manuscript submission, archive the tagged release with a DOI-issuing service such as Zenodo and
insert the resulting DOI in `CITATION.cff`, the manuscript, and the final data-availability statement.

## Manuscript-ready statement

> **Data availability.** No external empirical data were used in this study. All numerical results are
> generated deterministically from the version-controlled source code, notebooks, and configuration
> files in the QHE-EJP repository. A tagged archival release of the code package will be deposited in a
> DOI-issuing repository before publication; the final DOI will be cited here and in the software
> citation metadata.

## Scope limitation

The release does not claim that every future manuscript figure already exists. In particular, time-domain
wave-packet dynamics, current maps, velocity agreement, and defect-routing results require their own
validated implementation stage before they may be described as available numerical outputs.
