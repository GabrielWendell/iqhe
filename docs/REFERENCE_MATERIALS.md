# Reference-material register

This repository distinguishes reproducible source code from unpublished manuscript-support material.

| Material | Purpose | Storage policy | Status |
|---|---|---|---|
| Legacy notebook | Provenance of the original prototype implementation | Retained unmodified under `legacy/` with checksum | Included |
| Manuscript draft | Editorial and scientific reference during revision | Keep under controlled author-team storage unless an approved preprint is released | External/private |
| EJP readiness checklist | Implementation and submission plan | Keep as controlled project documentation; summarize operational requirements in `docs/` | External/private |

Do not upload unpublished manuscript PDFs, reviewer comments, or third-party material to a public repository without author approval and license verification.
