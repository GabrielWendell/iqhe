# Figures

This directory is reserved for reproducible publication and teaching figures.

## Rules

- A figure must be generated by a version-controlled script or notebook calling a reusable module.
- Do not manually edit figure labels, curves, colors, or panel content after export.
- Use `figures/generated/` for local outputs; it is ignored by Git.
- Commit only small, reviewed, final reference figures when there is a documented reason to preserve them.
- Each manuscript figure should have a corresponding builder function in `src/qhe_ejp/viz/` and an invocation in `scripts/`.
